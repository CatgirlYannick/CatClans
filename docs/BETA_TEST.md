# Beta Test Checklist

1. Start on a clean Paper 1.21.x server with Java 21.
2. Verify startup with and without optional integrations.
3. Create, edit, join, leave, transfer, and delete clans.
4. Test role names, priorities, individual permissions, and rank-pyramid enforcement.
5. Test bank deposits, withdrawals, custom chat amounts, refunds, and logs.
6. Test vault item transfer, rollback, paging, and 14-day logs.
7. Test home safety, limits, set, teleport, and delete actions.
8. Test alliance requests, ally chat, wars, admin war end, and scoring.
9. Test battlepass XP, claimable rewards, milestones, and unlocks.
10. Test rankings, ties, negative points, and daily activity awards.
11. Verify placeholders never trigger database work.
12. Profile MSPT, heap growth, GC pauses, and SQL latency with Spark.

Do not promote the beta until all destructive-action confirmations and rollback paths have been exercised.
