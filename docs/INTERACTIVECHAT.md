# InteractiveChat

InteractiveChat support is optional and configured in `integrations.yml`. PlaceholderAPI remains the stable data bridge.

Install PlaceholderAPI and InteractiveChat, enable both integrations, and use `%catclans_*%` placeholders in supported chat formats. CatClans does not require LuckPerms suffix mutations and removes clan tags automatically when a player leaves a clan.
