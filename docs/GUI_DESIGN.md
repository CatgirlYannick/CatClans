# GUI Design

The interface uses centered inventory layouts, black filler panes, purple top and bottom frames, non-italic MiniMessage text, RGB support, and Small Caps.

- Filler panes have no name, lore, or tooltip.
- Back arrows return to the immediately previous GUI.
- Close actions use `Close`, never a sharp-s character.
- Risky actions such as kicks, invitations, deletion, and transfers use confirmation windows.
- Clan editing uses chat input instead of an anvil GUI.
- The clan profile exposes members, permissions, roles, battlepass, bank, vault, homes, and diplomacy according to access rights.
- Battlepass filler is gray; locked levels use red panes, reached levels use green concrete, and every fifth level is a red concrete milestone until reached.

All slots, materials, labels, and lore are configurable in `gui.yml`.
